# سه‌جه‌ره — iPhone Viewer

Sorani Kurdish read-only web app. It reads public trees and GEDCOM files from the existing family-tree-sync repository. It does not edit or upload data and does not require login. Family records and photos remain public.

## Publish

Copy this folder's contents to the docs directory of your local family-tree-sync repository, then commit and push using your usual GitHub process. In GitHub, open Settings → Pages, choose Deploy from a branch, select main and /docs, then save. Expected address: https://simar-adak.github.io/family-tree-sync/.

## Add to iPhone

Open the published site in Safari, tap Share → Add to Home Screen, enable Open as Web App if offered, then tap Add. The Viewer needs internet to load tree records. This is an installable website, not a native App Store app; native iOS builds require macOS and Xcode.
